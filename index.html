Deployment note

EatSongBrew needs PHP hosting

This app is a PHP project and cannot run directly on Vercel as-is. Vercel does not execute the PHP files in htdocs/ the way a PHP host does.

The app is intended to run from a PHP-enabled server or local PHP environment, for example with:
php -S localhost:8000 -t htdocs

To deploy successfully, use a PHP hosting provider such as Render, Railway, Hostinger, cPanel hosting, or convert the project into a Node/Vercel app.

For local testing, open:
http://localhost:8000/index.php
