# EatSongBrew

This repository now includes the extracted project files under `htdocs/` and a cleaned-up, arranged structure for the app.

## Included
- `htdocs/index.php` and `htdocs/index.html`
- `htdocs/login.php` and `htdocs/register.php`
- `htdocs/my_account.php` and `htdocs/admin.php`
- `htdocs/db.php` and `htdocs/setup_db.php`
- `htdocs/css/style.css`
- `htdocs/js/script.js` and `htdocs/js/auth.js`
- `htdocs/eatsongbrew.sql`

## Setup
1. Ensure PHP is installed.
2. Run `php htdocs/setup_db.php` once to initialize the local SQLite database.
3. Serve the project from the `htdocs` directory with your preferred PHP server.

## Notes
The original archive file (`htdocs.zip`) was kept in the repository root, while the app was arranged into a usable project layout so it can be opened and fixed more easily.
